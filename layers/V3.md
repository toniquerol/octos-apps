# OcToS Layers · V3.0

Versión base: Layers 2.8; la funcionalidad V3 se carga exclusivamente en Layers a través de `shared/theme.js`. La plantilla muestra V3.0 mediante `shared/theme.json`. Los módulos `layers/v3.css` y `layers/v3.js` no afectan a Drive, Carto, Rain ni Meteo.

## Cambios

- **Distribución horizontal:** biblioteca oficial, inventario de recursos, ficha técnica vertical y visor cartográfico ocupando todo el ancho restante. La ficha se puede redimensionar horizontalmente. En móvil se apilan ficha y mapa.
- **Comparación 2D:** botón ↔ en el mapa. Separador arrastrable horizontalmente: lado izquierdo, mapa base sin superposiciones; lado derecho, mapa base más capas seleccionadas. Se sincronizan escala, posición y desplazamientos. Para mapas Liberty y estilos MapLibre se usa un segundo lienzo de referencia; para mapas IGN con Leaflet se utiliza un segundo mapa de referencia. El comparador no se activa durante el modo terreno 3D.
- **GetCapabilities WMS:** cada subcapa dispone de casilla y control individual de opacidad. Se pueden superponer varias subcapas simultáneamente del mismo servicio WMS; los identificadores activos se muestran separados por comas. Las selecciones y opacidades se almacenan en el catálogo local del navegador. No se modifican automáticamente los archivos JSON compartidos.
- **Compatibilidad:** se conservan el resto de tipos OGC, los mapas base actuales, la edición y aprobación de entradas, las miniaturas, el catálogo y las exportaciones.

## Verificaciones

Comprobación sintáctica JavaScript realizada. Se requiere comprobación visual en navegador con red de los fondos Leaflet/MapLibre y de los servicios WMS reales, dado que la disponibilidad de GetCapabilities/teselas puede estar limitada por CORS, credenciales o cobertura.
