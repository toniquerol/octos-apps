# OcToS Rain V7 — Terreno y partículas en 3D

## Novedades
- Botón **3D / 2D** en la cabecera. La vista 2D sigue utilizando Leaflet.
- El relieve 3D se construye con las **elevaciones reales del MDT o mosaico GeoTIFF importado**, no con un plano decorativo. Se reduce exclusivamente la densidad de la malla visual a un máximo de 256×256 vértices; el cálculo D8 subyacente conserva su propia resolución.
- Cámara orbital: arrastrar para girar, rueda para acercar. Exageración vertical ajustable (1–12×).
- El visor intenta aplicar a la superficie 3D **el mismo fondo** IGN, PNOA, relieve, MDT visual o LiDAR que esté seleccionado arriba. Compone teselas web Mercator como textura sobre el MDT georreferenciado.
- Si el proveedor cartográfico no permite CORS o WebGL, el terreno se muestra con sombreado por altura y se indica el motivo, sin alterar el MDT.
- Las partículas visuales de lluvia/drenaje siguen las **mismas rutas D8** en 2D y 3D mientras se reproduce Play.
- El control de opacidad del mapa base se ha integrado en el desplegable **Mapas** y regula la mezcla de textura cartográfica sobre el relieve 3D sombreado.

## Conservado
Asistente de seis pasos V5.2, mapa 2D, descarga/importación de MDT, mosaico V4, lluvia y volumen estimado, curvas de nivel, cauces, hidrografía e inundaciones V6.

## Limitaciones técnicas
- Para mostrar relieve 3D se necesita primero importar un **MDT con cotas**; las imágenes LiDAR visuales no constituyen por sí solas un DEM.
- Se requiere WebGL y conexión a Internet para cargar Three.js desde jsDelivr y para descargar las teselas de textura.
- Puede fallar la textura de ciertos fondos por **CORS, cobertura o disponibilidad**: el sombreado del DEM queda como alternativa.
- Las partículas siguen un camino **topográfico D8**, sin resolver profundidades, tiempos físicos de propagación ni ecuaciones hidráulicas 2D; la velocidad de animación no equivale a m/s.
- Los WMS temáticos de inundación y las geometrías de análisis siguen visibles y editables en la vista 2D, pero **no se han proyectado sobre la malla 3D** en V7.
- La malla 3D se muestrea a 256 × 256 como máximo por rendimiento; esto no modifica ni simplifica el modelo numérico utilizado en hidrología.
- No se ha realizado una **prueba visual end-to-end con MDT02 real** desde el navegador de esta sesión.
