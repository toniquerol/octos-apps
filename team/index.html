Instrucciones para desplegar el Worker en Cloudflare

Primero se despliega el Worker en tu cuenta de Cloudflare. Una vez vinculado, puedes pegar la clave aquí: viajará por HTTPS y se almacenará cifrada en el servidor, nunca en GitHub ni en el navegador.

El PIN de OcToS Team no sustituye la contraseña del Worker. No uses este campo si la URL no corresponde a tu propio servicio Cloudflare. La clave no se incluye en los registros y se borra del formulario al confirmar.

Petición

Flujo previsto: Controlador → Jarvis (microtarea) o reunión de responsables (proyecto) → departamentos → Dirección → propietario si persiste una decisión. La API actual sigue limitada a Dirección, A03 y A04. Esta prueba no modifica repositorios.
