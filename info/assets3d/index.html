OcToS 3D Assets

Biblioteca de modelos y conversión GLB → HTML

Aplicación para visualizar, catalogar y exportar objetos 3D como HTML independientes, sin servidores de almacenamiento.

Abrir 3D Assets

Funciones

  • Importar modelos .glb mediante selección o arrastre.
  • Visualizar la geometría, los materiales y las animaciones compatibles con Three.js.
  • Consultar mallas, triángulos y tamaño del archivo.
  • Optimizar geometría con glTF-Transform y meshoptimizer, cuando el modelo sea compatible.
  • Guardar modelos con nombre, miniatura y etiquetas en IndexedDB.
  • Exportar un HTML por modelo y descargar el GLB.
  • Hacer copia de seguridad y restaurarla en otro navegador.

Almacenamiento y límites

La base de datos se mantiene en el navegador y equipo actuales. No existe sincronización entre dispositivos. Borrar los datos del sitio puede borrar los modelos; las copias de seguridad permiten recuperarlos. La aplicación acepta GLB 2.0; GML geoespacial es otro formato distinto.

Los HTML exportados incluyen los datos 3D dentro del propio archivo, pero necesitan Internet para cargar Three.js. La optimización con reducción puede afectar al detalle y no es compatible con todas las extensiones glTF.
